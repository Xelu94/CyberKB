# resumen_master_clase16

**Categoría:** forense
**Tags:** #wireshark, #pcap, #smb, #ntlm, #psexec, #sql-injection, #blue-team, #lateral-movement, #network-forensics, #cyberdefenders

## Contenido

Clase práctica de análisis forense de red usando Wireshark y CyberDefenders. Se analizan dos escenarios reales: movimiento lateral mediante PSEXEC sobre SMB con autenticación NTLM en entorno Windows corporativo, y un ataque de SQL Injection sobre tráfico HTTP sin cifrar. La metodología parte de una visión macro (jerarquía de protocolos y conversaciones) antes de profundizar en paquetes individuales.
