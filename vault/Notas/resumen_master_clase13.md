# resumen_master_clase13

**Categoría:** forense
**Tags:** #esteganografia, #osint, #forense, #metadatos, #analisis-binario, #exiftool, #binwalk

## Contenido

Sesión práctica sobre esteganografía en el contexto de OSINT, cubriendo técnicas para ocultar y detectar información dentro de archivos aparentemente normales. Se trabajan herramientas como file, strings, exiftool y binwalk para analizar imágenes en busca de datos ocultos, metadatos y archivos embebidos. Se abordan tanto la perspectiva ofensiva (ocultar datos para evadir filtros) como la defensiva/forense (detectar y extraer información oculta como evidencia).
