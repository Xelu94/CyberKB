# resumen_master_clase9

**Categoría:** osint

## Contenido

Módulo práctico de OSINT del Máster de Ciberseguridad Wolf Academy donde se realiza un ejercicio completo de footprinting de persona a partir de un número de teléfono. Se demuestra la cadena completa: teléfono → nombre → LinkedIn → empleo/trayectoria → precio/hora → deporte → DNI → correo → contraseñas filtradas → alias. Se cubren herramientas especializadas en reconocimiento facial (PimEyes), búsqueda de usernames (Sherlock, Maigret, What's My Name), detección de filtraciones (Have I Been Pwned, LeakRadar) y técnicas de Google Dorks para localizar PDFs con datos sensibles filtrados por terceros.
