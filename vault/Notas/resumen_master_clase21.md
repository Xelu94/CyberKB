# resumen_master_clase21

**Categoría:** metodologia
**Tags:** #metasploitable2, #vsftpd, #backdoor, #privilege-escalation, #telnet, #ftp, #metasploit, #nmap, #sudo, #GTFOBins, #reverse-shell, #RCE

## Contenido

Sesion practica de pentesting sobre Metasploitable 2 cubriendo la metodologia completa de 5 fases: reconocimiento, enumeracion, analisis de vulnerabilidades, explotacion y post-explotacion. Se explotan servicios FTP (vsftpd 2.3.4 backdoor) y Telnet mediante Metasploit y scripts Python, culminando en escalada de privilegios a root via sudo -l. Se introduce la combinacion FTP + web como vector RCE y el uso de GTFOBins para escalada.
