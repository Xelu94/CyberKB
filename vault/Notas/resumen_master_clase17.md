# resumen_master_clase17

**Categoría:** forense
**Tags:** #wireshark, #web-shell, #lolbins, #reverse-shell, #pcap, #forense-redes, #certutil, #netcat, #aspnet, #http-https

## Contenido

Sesión práctica de análisis forense sobre capturas de red (PCAP) que cubre la metodología de investigación con Wireshark, incluyendo identificación de actores, análisis de subida de web shells en ASP.NET, uso de LOLBins para descarga de herramientas y establecimiento de reverse shells con Netcat. Se compara también tráfico HTTP vs HTTPS y se introduce el concepto de Living Off the Land Binaries como técnica de evasión.
