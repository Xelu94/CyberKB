# resumen_master_clase18

**Categoría:** web-hacking
**Tags:** #SQL-Injection, #Wireshark, #forense-web, #ISO-27001, #NIS2, #ISO-42001, #LLM-hacking, #prompt-injection, #URL-encoding, #PCAP

## Contenido

Sesión que cubre fundamentos de SQL Injection mediante análisis forense de un PCAP en Wireshark, identificando el fichero vulnerable search.php y el uso de URL encoding (%27 como comilla simple) para inyectar queries. Se introduce la lógica booleana de OR 1=1 y cómo la falta de sanitización de inputs provoca errores 500 que confirman la vulnerabilidad. Paralelamente se introduce normativa de ciberseguridad (ISO 27001, ISO 42001, NIS2) y se anuncia un módulo de hacking a LLMs incluyendo prompt injection.
