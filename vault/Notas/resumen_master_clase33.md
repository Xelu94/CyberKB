## Contenido

Sesión de repaso que cubre el flujo completo de la máquina Bastion (HTB Tier 2), con énfasis en estabilización de shell inversa y escalada de privilegios mediante sudo vi. Se introduce también la máquina Oopsie con vulnerabilidades IDOR y File Upload. El documento detalla paso a paso cómo convertir una shell tonta en una pseudo-terminal completa y cómo explotar un misconfigured sudo para obtener root a través del editor vi.
