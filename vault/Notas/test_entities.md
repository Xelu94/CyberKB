## Resumen

El documento cubre técnicas de ataque web como SQL Injection y XSS, junto con herramientas de testing como sqlmap y Burp Suite. Se menciona la vulnerabilidad crítica Log4Shell (CVE-2021-44228) que permite ejecución remota de código. También se referencian conceptos fundamentales como la tríada CIA, el framework MITRE ATT&CK y protocolos de red como TLS, TCP y HTTP.

## Contenido

SQL Injection es una tecnica de ataque que permite ejecutar consultas SQL maliciosas.
Herramienta sqlmap automatiza la deteccion de SQLi. OWASP Top 10 incluye SQLi como A03.
XSS o Cross-Site Scripting inyecta scripts en paginas web. Burp Suite se usa para testing.
Nmap es esencial para reconocimiento. TCP y HTTP son protocolos fundamentales.
CVE-2021-44228 Log4Shell permite RCE en Apache Log4j. CIA Triad: Confidencialidad, Integridad, Disponibilidad.
MITRE ATT&CK es un framework de metodologia. TLS protege comunicaciones.
