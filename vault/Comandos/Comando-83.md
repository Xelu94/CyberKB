# netstat -ano

**SO:** windows
**Herramienta:** netstat

```bash
netstat -ano
```

Muestra todas las conexiones activas, puertos en escucha, direcciones numéricas y el PID del proceso asociado

**Flags:** `-a`, `-n`, `-o`, `-b`
