# taskkill /IM notepad.exe /F

**SO:** windows
**Herramienta:** taskkill

```bash
taskkill /IM notepad.exe /F
```

Termina procesos por nombre de imagen o PID de forma forzada

**Flags:** `/IM`, `/PID`, `/F`
