# tasklist | findstr [PID]

**SO:** windows
**Herramienta:** tasklist

```bash
tasklist | findstr [PID]
```

Filtra la lista de procesos activos por PID para identificar el ejecutable asociado a una conexión sospechosa detectada con netstat
