# ipconfig /all

**SO:** windows
**Herramienta:** ipconfig

```bash
ipconfig /all
```

Muestra configuración completa de red: IP, máscara, gateway, DNS y estado DHCP de todos los adaptadores

**Flags:** `/all`, `/release`, `/renew`, `/flushdns`
