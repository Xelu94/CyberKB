# find / -name {} 2>/dev/null

**SO:** linux
**Herramienta:** find

```bash
find / -name {} 2>/dev/null
```

Busca archivos en todo el sistema redirigiendo errores a null, útil en reconocimiento

**Flags:** `-name`
