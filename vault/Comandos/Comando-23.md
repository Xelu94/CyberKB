# tail -f fichero.txt

**SO:** linux
**Herramienta:** bash

```bash
tail -f fichero.txt
```

Monitoriza un fichero en tiempo real, útil para seguir logs como /var/log/auth.log en máquinas comprometidas

**Flags:** `-f`
