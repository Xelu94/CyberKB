# du -h | sort -rh | head -10

**SO:** linux
**Herramienta:** du

```bash
du -h | sort -rh | head -10
```

Muestra las 10 carpetas que más espacio ocupan ordenadas de mayor a menor

**Flags:** `-h`, `-rh`
