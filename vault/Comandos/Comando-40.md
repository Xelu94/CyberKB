# find /home/kali -name "*.tmp" -delete

**SO:** linux
**Herramienta:** find

```bash
find /home/kali -name "*.tmp" -delete
```

Busca y borra todos los archivos .tmp en el home de kali

**Flags:** `-name`, `-delete`
