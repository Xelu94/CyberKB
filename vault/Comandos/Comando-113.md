# tar -z -cf /var/my-backup.tgz /home/asimina/

**SO:** linux
**Herramienta:** tar

```bash
tar -z -cf /var/my-backup.tgz /home/asimina/
```

Crea un archivo comprimido gzip tar del directorio home del usuario

**Flags:** `-z`, `-c`, `-f`
